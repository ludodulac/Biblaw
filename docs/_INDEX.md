## Règle sémantique

Une proximité lexicale n'est pas une relation conceptuelle. Un mot contenu dans le nom d'un thème n'est pas automatiquement une composante conceptuelle de ce thème. Pour une relation ambiguë, conserver la frontière avec le type concurrent plutôt que forcer une étiquette certaine.
