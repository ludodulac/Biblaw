## 4. Problèmes documentaires encore ouverts

- **Concurrences d'identités et doublons** : deux ou plusieurs JSON revendiquent une seule note réellement imprimée. Un rapprochement lexical ne permet ni d'élire un identifiant ni de supprimer le doublon, notamment les conflits avec d'anciens dossiers 063.
- **Extractions composites** : une note est suivie dans le même champ `text` de versets, de prières, d'une autre note ou d'une continuation faussement capturée. Le découpage exige un plan de provenance sûr sans perte ni duplication.
- **Psaume contre prière** : certains appels se situent physiquement après la fin d'un psaume, dans une prière (numérotée `Pr.`). Le rattachement canonique reste à trancher explicitement.
- **Pages / versets / limites de texte** : quelques pages sources et numéros revendiqués ne permettent pas encore d'attribuer une note sans hypothèse, parfois parce que le texte amont est tronqué.
- **CI générale** : au début de 064-20, **45 SUCCESS / 48**, avec trois échecs préexistants *Audit theme entry identity*, *Browser smoke - lexical occurrence expansion*, *BIBLAW 058 corpus browse mobile*. Aucune réparation de ces workflows dans la mission. Les tests spécialisés 064-20 sont suivis séparément et consignés dans [064-20_VERDICTS.md](064-20_VERDICTS.md).

Ces points sont **ouverts mais hors du périmètre de clôture**. Aucun traitement des 46 anomalies n'est autorisé par 064-20. Les 77 notes plus problématiques de l'inventaire 060 et les autres catégories ne font pas partie de ces **192** ; ce rapport ne statue pas sur elles.
